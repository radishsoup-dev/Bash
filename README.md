1 Introduction
1.1 What is Bash?
command language interpreter
是“Bourne-Again SHell”的缩写

1.2 What is a shell?

a shell is simply a macro processor that executes commands.
将文本和符号进行扩展以创建更大表达式的功能

其编程语言特性允许将这些实用程序组合起来
可以交互式或非交互式地使用。
允许同步或异步地执行 GNU 命令。

重定向构造允许对这些命令的输入和输出进行细粒度的控制。

提供了一小部分内置命令（builtins），用于实现那些通过独立实用程序难以获得或不方便实现的功能。
例如，cd、break、continue 和 exec 无法在 Shell 外部实现，因为它们直接操纵 Shell 自身。
而 history、getopts、kill 或 pwd 等内置命令本可以在独立的实用程序中实现，但作为内置命令使用起来更为方便。

与任何高级语言一样，Shell 提供了变量、流程控制结构、引用和函数。

提供了专门交互功能包括作业控制、命令行编辑、命令历史和别名。

filename（文件名）用于标识文件的字符串。

在 Bash 中，一个 Job 通常由一个管道（Pipeline）及其包含的全部进程组成。Linux 内核提供了 Process Group 这一进程组织机制。
在终端按下 Ctrl+C 时，终端驱动程序可以向前台进程组发送 SIGINT 信号。  
job control（作业控制）​ 用户可以有选择地停止（挂起）和重新启动（恢复）进程执行的一种机制。
metacharacter（元字符）​ 当未被引号引用时，用于分隔单词的字符。元字符包括空格、制表符、换行符，或是下列字符之一：|、&、;、(、)、< 或 >。
name（名称）​ 仅由字母、数字和下划线组成，且以字母或下划线开头的单词。名称被用作 shell 变量和函数名，也称为标识符（identifier）。
operator（操作符）​ 控制操作符或重定向操作符。有关重定向操作符的列表，请参阅第 3.6 节[重定向]。操作符至少包含一个未被引号引用的元字符。

process group（进程组）​ 一组相关的进程，每个进程都具有相同的进程组 ID。
process group ID（进程组 ID）​ 在进程组生存期内代表该进程组的唯一标识符。
reserved word（保留字）​ 对 shell 具有特殊含义的单词。大多数保留字用于引入 shell 流程控制结构，例如 for 和 while。
return status（返回状态）​ 退出状态（exit status）的同义词。
signal（信号）​ 内核用以通知进程系统中发生事件的机制。
special builtin（特殊内建命令）​ 被 POSIX 标准归类为特殊的 shell 内建命令。
token（标记）​ shell 视为单一单元的字符序列。它可以是单词或操作符。
word（单词）​ shell 作为单元处理的字符序列。单词不得包含未被引号引用的元字符。

3 Basic Shell Features
3.1 Shell Syntax
当 shell 读取输入时，它会经历一系列操作。如果输入指示了注释的开始，shell 会忽略注释符号（#）以及该行剩余的部分。
粗略地说，shell 读取输入并利用引用规则将输入划分为单词和操作符，以此决定为各种单词和字符赋予何种含义。
接着，shell 将这些标记解析为命令及其他结构，移除某些单词或字符的特殊含义，对另一些进行扩展，按需重定向输入和输出，执行指定的命令，等待该命令的退出状态，并使该退出状态可用于进一步的检查或处理。

以下是 shell 在读取和执行命令时的简要操作流程。
从文件、作为 -c 选项的字符串或从用户终端读取输入。
依据引用规则，将输入拆分为单词和操作符。这些标记由元字符分隔。此步骤会执行别名扩展。
将标记解析为简单命令和复合命令。
执行各种 shell 扩展，将扩展后的标记拆分为文件名列表以及命令和参数。
执行所有必要的重定向，并从参数列表中移除重定向操作符及其操作数。
执行命令。
可选地等待命令完成，并收集其退出状态。

引用用于去除某些字符或单词对 shell 的特殊含义。
引用可用于禁用对特殊字符的特殊处理、防止保留字被识别为保留字，以及阻止参数扩展。
注意命令历史扩展功能。共有四种引用机制：转义字符、单引号、双引号和美元单引号。

反斜杠 \ 是 Bash 的转义字符。它会保留其后下一个字符的字面值，去除该字符原本可能具有的特殊含义，换行符除外。
如果出现 \ 后接换行符的组合（\newline），则该组合会被视为续行符（即从输入流中移除并实际上被忽略）。

将字符用单引号（'）括起来，会保留引号内每个字符的字面值。单引号之间不能出现单引号，即使前面加了反斜杠也不行。

将字符用双引号（"）括起来，会保留引号内所有字符的字面值，但以下字符除外
$ ' ！
当 shell 处于 POSIX 模式时，即使在启用了历史扩展的情况下，! 在双引号内也不具有特殊含义。
$ ' " 、 newline 
如果启用了历史扩展，则会执行历史扩展
* 和 @ 在双引号内具有特殊含义
形式为 $'string' 的字符序列被视为一种特殊的单引号。

在双引号字符串前加上美元符号 $

在非交互式 shell 中，或在启用了 shopt 内建命令的 interactive_comments 选项的交互式 shell 中（见第 4.3.2 节[Shopt 内建命令]），以 # 开头的单词会引入一条注释。

简单命令是最常被执行的命令类型。它只是一系列由空白符分隔的单词，由 shell 的某个控制操作符终。
第一个单词通常指定要执行的命令，其余单词则作为该命令的参数。

管道的本质是：将一个命令的输出连接到另一个命令的输入，使多个命令能够组合起来完成工作。

|：只连接标准输出  |&：同时连接标准输出和标准错误  

! 取反的是整个管道的最终状态  

time 是 Bash 的一个关键字，可以统计管道的执行时间。  

Bash 有一个容易忽略的行为：默认情况下，整个管道的退出状态由最后一个命令决定。

set -o pipefail

[time [-p]] [!] command1 [ | 或 |& command2 ] ...

列表是一个或多个管道组成的序列，彼此间用操作符 ;、&、&& 或 || 分隔，并可以选择性地以 ;、& 或换行符终止。
&& 和 || 具有相同的优先级，其次是 ; 和 &，它们也具有相同的优先级。
可以出现一个或多个换行符来分隔命令，其效果等同于分号。

命令由控制操作符 & 终止，shell 会在子 shell 中异步执行该命令。这被称为在后台执行命令，此类命令也被称为异步命令。shell 不会等待命令完成，返回状态为 0（真）。

用 ; 分隔的命令会顺序执行；shell 会依次等待每个命令终止。返回状态是最后执行的命令的退出状态。

AND 列表的形式为：command1 && command2
当且仅当 command1 返回退出状态零（成功）时，才执行 command2。

OR 列表的形式为：command1 || command2
当且仅当 command1 返回非零退出状态时，才执行 command2。
